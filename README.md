# Notification Studio

A practice project for building a front-end interface to create, edit, and preview customer communication messages with real-time updates.

## Purpose

Educational project to practice:
- Semantic HTML5 structure
- CSS architecture with custom properties and BEM methodology
- Desktop-first responsive design
- Vanilla JavaScript (ES6+) for component logic
- Real-time content preview
- Light/dark theme implementation
- Custom accessible UI components

## Tech Stack

- **HTML5**, **CSS3**, **Vanilla JavaScript (ES6+)**
- CSS Grid & Flexbox for layouts
- CSS Custom Properties for theming
- Roboto font family (Regular, Medium, Bold) via `@font-face`
- SVG icons and PNG mockups
- No frameworks or external dependencies

## Features

- **Real-time Preview**: Dynamic push notification preview with iPhone mockup
- **Custom Select Components**: Accessible dropdowns with keyboard navigation
- **Theme Switching**: Light/dark mode
- **Responsive Layout**: Desktop-first approach with breakpoints
- **Template Editor**: Form-based editor for notification content

## Design Approach

- **Desktop-first**: Base styles target large screens, `max-width` media queries for smaller breakpoints
- **BEM-like naming**: Block__element--modifier structure
- **CSS Variables**: Theme colors with RGB versions for `rgba()` usage
- **Rem units**: Scalable typography and spacing

## Notes

This is an **educational project** demonstrating front-end development practices without frameworks. All assets are placeholders or custom-made for learning purposes.
